# Professor Drive Setup — Meeting Checklist

Use this checklist when meeting with the instructor to move all course files from personal/TA Drive to the **professor’s Google Drive**. After the meeting, paste each file ID into [`_data/drive_links.yml`](_data/drive_links.yml) and push to `main` (see [README.md](README.md#updating-course-materials)).

## Folder structure (recommended)

Create one root folder, e.g. `QMSS 5070 Spring 2026`, with subfolders:

| Subfolder | Contents |
|-----------|----------|
| `Syllabus` | Spring 2026 syllabus |
| `Reference` | GIS cheat sheet |
| `Slides` | Lecture `.pptx` files |
| `Labs` | Lab ZIPs (Week2_Lab1.zip … Week14_Lab12.zip) |
| `Homework` | HW 1–8 `.docx` (+ supporting data folders if any) |
| `Exams` | Midterm, final paper assignment |
| `Recordings` | Lab session videos |

**Sharing:** Each file → Share → **Anyone with the link** → **Viewer**.

## Link format for the website

For each file, copy either the full URL or just the **file ID** (between `/d/` and `/view`):

```
https://drive.google.com/file/d/FILE_ID/view?usp=sharing
```

Paste IDs into `_data/drive_links.yml` under `professor_drive:`.

## After the meeting

1. Fill in `professor_drive` IDs in [`_data/drive_links.yml`](_data/drive_links.yml).
2. Set `use_professor_drive: true` in the same file.
3. Run `bundle exec jekyll serve` locally and click every link in the schedule.
4. Commit, push to `main`, confirm GitHub Actions deploy is green.
5. Announce only: **https://manasagnihotri.github.io/GIS-Course/**
